## 01-cacharel-checkout

Интернет-магазин одежды. Своё оформление заказа (`cacharel:order`) вместо `sale.order.ajax`, на D7 Sale: курьер, ПВЗ Ozon, самовывоз с проверкой наличия, купоны, профили покупателя, пересчёт без перезагрузки.

- `sale_payment/sberbankqr/` - обработчик платёжной системы: оплата по QR Сбербанка через СБП, проверка статуса через API (`ICheckable`) + агент

## 02-britannica-restaurant-order

Ресторан. Модуль `westpower.fiji`: заказ и оплата со столика с синхронизацией с кассой R-Keeper, частичная оплата, очередь вызова официанта.

- `lib/Service/OrderService.php` - корзина, заказ, оплата, синхронизация с кассой
- `lib/Repository/Client/RKeeperClient.php` - XML-интерфейс R-Keeper
- `lib/Controller/OrderController.php` - AJAX и уведомления от кассы

## 03-winner-orders-payments

Онлайн-платформа (бэкенд и Vue). Модуль `westpower.winnnner`, главное - платёжная часть:

- `lib/PaySystem/Handlers/Base.php` - общий класс платёжки, реализации `Cryptomus`, `Pult24`, `Inner`
- `lib/PaySystem/Manager.php` + `lib/Controller/PaymentController.php` - приём уведомлений с проверкой подписи

## Обработчики доставки

Штатные обработчики служб доставки (`\Bitrix\Sale\Delivery\Services\Base`), подключаются из `/local/php_interface/include/sale_delivery/`.

### 04-avokitchen-delivery

Доставка еды. Зоны доставки - полигоны в инфоблоке, у каждой своя стоимость и порог бесплатной доставки.

### 05-kruassan-delivery

Доставка из сети ресторанов. Зоны привязаны к ресторанам: адрес определяет, из какого ресторана везут заказ.

### 06-konturterm-delivery

Магазин сантехники и инженерного оборудования. Тарифы в инфоблоке по способу доставки, отдельно для города и за городом:
- бесплатно для отдельных типов плательщиков или от суммы заказа
- за городом доплата за километр. Расстояние по дорогам приходит с карты, сервер не даёт ему быть меньше расстояния от адреса до границы города
- подъём на этаж: тариф по весу заказа и крупногабаритным товарам, с лифтом и без

## 07-coxo-pay-restriction

Магазин электроники. Ограничение платёжной системы по разделам каталога (`\Bitrix\Sale\Services\Base\Restriction`): платёжка скрывается, если в корзине есть товар из выбранных разделов или их подразделов. Разделы выбираются в настройках ограничения.
